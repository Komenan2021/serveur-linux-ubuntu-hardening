# Captures d'écran

Dépose ici tes images avec les noms exacts indiqués dans le README du projet (section « Captures d'écran »).
Dès qu'une image porte le bon nom, elle s'affiche automatiquement dans le README.

Astuce : avant de publier, masque les adresses IP publiques, mots de passe et noms de clients sur tes captures.
